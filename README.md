1. git status 
2. git add . (files) - добавляет файлы в подготовительную область. stage 
3. git commit -m "comment "
4. git log / git log --oneline
5. git push [repository] [branch_name]  
6. git remote -v  просомтр имени репозитория
7. git reset - обнуление изменений, попавших в stage (git add)
8. git diff просомтр строк , где произоошли изменения
9. git branch  - просмотр ветки
10. git branch [название ветки]  - установить новую ветку
11. git chekout [название ветки]  - перейти в нужную ветку
